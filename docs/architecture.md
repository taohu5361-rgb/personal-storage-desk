# 项目结构与数据关系

| 路径 | 用途 |
| --- | --- |
| `src/` | React 页面、组件、样式、画布交互与单元测试 |
| `src-tauri/src/` | Tauri 命令、SQLite 数据操作、本地文件处理与 Rust 测试 |
| `src-tauri/migrations/` | 被 Rust 源码引用的数据库迁移，构建时必须完整保留 |
| `src-tauri/capabilities/` | Tauri 能力配置 |
| `src-tauri/icons/` | 应用图标，来源见图标说明 |
| `scripts/` | 构建辅助、主题审计、合成交互夹具与测试脚本 |
| `package-lock.json` / `src-tauri/Cargo.lock` | 固定依赖解析结果 |

数据层级是 Workspace → Category → Asset。界面中的“模型”沿用历史命名，对应 Workspace 容器，并不表示已经解析模型文件或关联 AI 推理能力。

分类外画布保存资产布局、分类文字、视觉分组与视口。资产详情内画布与外画布分别保存各自状态；不应把分类布局与资产内画布布局合并。资产自由文字的内容和样式共享，标准详情与内画布分别保存几何布局。样图、提示词、案例备注的多个展示方式引用同一份记录。附属备注卡片的浮动、停靠和收纳是界面布局能力，不代表独立复制了材料。

SQLite 保存应用记录与路径，本地文件另行保管。原文件和封面可以采用不同保存方式。缩略图、预览等派生文件不应被误认为唯一原件。脚本模块目前为实验骨架，通过本机已有环境启动脚本。

兼容标识 `local.script.collection`、`script-collection.sqlite3`、Cargo crate 与旧设置键保留不变。品牌字符串与内部数据身份是两件事，改名前者不会自动改变后者。所有历史迁移都应保留，新增数据变化通过可验证的迁移处理。
