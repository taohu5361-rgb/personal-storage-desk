# 已知限制

项目处于早期开发阶段，当前交付不代表成熟稳定产品。界面和数据库结构可能继续变化。

- 主要验证平台为 Windows。WebView2、系统对话框、路径与字体行为依赖本机环境；浏览器夹具通过不能替代完整桌面验证。
- 没有内置 AI 推理、生图、模型解析或自动读取 ComfyUI 参数。界面“模型”是材料工作空间容器。
- “我的脚本”主要功能尚未开展，现有分类、登记与启动是实验原型。脚本依赖本机环境，无内置解释器或沙箱。
- 任意格式文件可以作为材料登记和保存，但不能保证每种格式都可直接预览。
- 数据库备份只有记录，没有原文件、样图或字体；改变托管目录不会自动迁移材料。引用路径失效时，需要恢复源文件位置或修复引用。
- 同一资产的标准详情与内画布共享文字内容 / 样式，但布局独立；分类外画布状态也不能代替资产详情状态。
- 当前 CSP 为 `null`、asset protocol 允许 `**`，并启用开发工具功能。保留这些设置是现有文件和字体读取的兼容需求，应用尚不能宣称已经过安全加固。
- 内部应用 identifier 与数据文件身份沿用历史值。release 版本不支持通过 debug 测试环境变量隔离数据。
- 首页列表 / 画布模式的分开内容管理，以及项目 / 子项目 / 孙项目嵌套，仍是规划，不属于本次实现。

新增功能或修复的验收应记录具体测试场景。未执行的输入法、触摸、生产运行与跨平台测试应明确标注，不把构建通过当作这些能力已经验证。
