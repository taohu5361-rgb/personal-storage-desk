# 黑白画布与安静网格

实际底色由外画布 `.asset-canvas`、内画布 `.asset-inner-canvas` 这两个固定 viewport 绘制。它们内部的 world 层只变换内容，外画布文字叠层保持透明。原来的深色主题规则直接覆盖 viewport 的底色与网格，导致分类面板保存白色后仍显示深色；内画布还使用独立的固定点阵，未接入分类设置。

现在 `canvasAppearance.js` 负责旧值兼容、分类/全局默认继承、网格间距和位置；两个 viewport 使用同一 CSS 渲染规则，主题不再覆盖画布选择。资产内画布继承所属分类，标准详情视图保持原有布局。

- 白色使用 `#ffffff`；黑色使用低刺激的近黑 `#181b20`。
- 无网格、柔和点阵、轻网格；底色和网格采用直接按钮切换。
- 100% 缩放下间距 64 CSS px。通过二倍层级自适应密度，10%–500% 缩放下屏幕间距保持 40–80 CSS px。网格位置跟随世界坐标原点，负坐标按间距取模，不依赖有限 world 元素的边界。
- 点半径 0.8px，白底点色 17% 深灰、黑底点色 16% 白；线宽 1px，白底线色 6.5% 深灰、黑底线色 5.5% 白。
- 删除画布自定义颜色和透明度控件，沿用原保存字段，不改动数据库表。旧浅色映射到白色、旧深色映射到黑色，读取时不重写旧记录。
- 名称、空画布提示、选中边框按底色适配；现有图片、备注、文字内容和用户保存的文字样式不重写。

验证脚本：

1. `node scripts/test-canvas-background.mjs <输出目录>`：真实 React 内外画布，主题/底色/网格组合，负坐标、10%–500% 缩放，中键平移、滚轮缩放、键盘按钮、窄窗口、浏览器重载；无页面错误。
2. `node scripts/test-canvas-background-native.mjs <绝对隔离目录>`：打包的 debug Tauri/WebView2，独立 SQLite 和 WebView 目录；真实保存、内画布继承、正常退出与重启恢复。
3. `npm run test:theme`、`npm run build:exe`。原生测试须先 `npm exec -- tauri build --debug --no-bundle`，两个脚本使用 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块路径，不安装依赖。

键盘测试同时修复了空格平移监听吞掉按钮空格操作的冲突；外画布文字叠层不再重复处理平移快捷键。
