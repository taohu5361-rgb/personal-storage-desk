# 连续拖动与单张图片十字轴

## 操作

- 普通移动保留小数坐标。智能吸附采用屏幕 6px 进入、10px 退出；拉出退出范围即可脱离。Alt 临时取消吸附。
- 网格吸附首次升级重置为关闭，此后保留用户主动选择。背景网格不限制坐标。
- 左键／右键点击图片或空白框选选中单张图片后，点击“排列”直接显示图片中心十字轴。名称和标签不计入图片区域。
- 更换选择保留轴；对同一中心图片再次点击“排列”关闭，对另一张图片点击重新建立。清除按钮或空闲时 Esc 关闭，切换画布清除。
- 十字轴开启时，单张图片拖动保持自由跟随。接近轴线的顶／底／中心或左／右／中心显示半透明落点框，屏幕 10px 进入、16px 退出，松手才吸附。
- Alt、拉远取消提示；Esc、指针取消、窗口失焦恢复拖动前布局。拖动与最终落点形成一次几何撤销记录。
- 中心图片旋转后轴仍水平／垂直；移动它时轴跟随，它不会吸附到自己的轴。锁定图片可作为中心。

## 实现与保存

canvasAxisGeometry.js 共享图片区域、中心和落点候选计算；canvasFrameQueue.js 合并高频指针事件，松手同步处理最新位置，取消丢弃待执行事件。内外画布在手势开始时缓存不变参考几何，保留未变化对象引用。普通吸附与轴线预览分别应用位置修正。

轴状态仅存在当前画布会话，不写数据库；复用现有联合保存、几何撤销、失败重试。不重新排列已有对象，不改变标准详情的文字布局。多对象排列行为本轮保留。

## 验收

- 123 项 JavaScript 几何、队列、数据与既有回归测试。
- test-axis-drag-ui.mjs：46 项交互检查；六个落点、普通磁吸脱离、三组 UI／画布缩放、旋转中心、锁定、取消、清除、网格偏好、最新松手位置、同帧 100 事件合并及真实鼠标路径耗时。
- test-axis-drag-native.mjs：14 项真实打包 WebView2／SQLite 检查；内外轴线拖动只预览、松手保存、一次撤销／重做、写锁失败重试、中文编辑和正常退出重启。
- 原有变换 13 项、文字 32＋30 项浏览器回归；小地图和中键平移回归；前端、主题和 Windows release 构建。

运行浏览器脚本需 PLAYWRIGHT_MODULE；桌面脚本另需 PYTHON_RUNTIME 和新的独立测试目录。桌面脚本使用已构建的 debug 程序并检查隔离数据库路径，保持日常数据库独立。物理系统输入法候选窗仍需人工验收。
