# 内外画布小地图验收

小地图由 `CanvasMinimap` 共用，外画布与独立内画布各有一个实例。默认展开，内外显示偏好分别保存在本地 WebView 存储中；标准详情和外画布嵌入文字层不重复显示。

- SVG 色块表示资产、文字、备注及分组；蓝色框表示当前视口，选中对象使用亮色描边。
- 右边缘与当前画布工具栏对齐，间隔 12 个界面单位；220×150，窄画布缩为160宽，空间不足暂时隐藏。
- 点击视口框外的位置定位；拖动视口框平移，缩放值保持不变。命中区域至少24个界面单位，映射在一次指针操作中固定；Escape或指针取消恢复原视口。
- 地图内滚轮、右键、双击和按键不会触发底层画布操作。方向键可平移视口。
- 外画布跟随搜索和分组收起状态；文字和备注使用矩形快照通知同步，无持续轮询。旋转内容使用共用几何函数计算世界顶点。
- 打开外画布背景面板时避让，关闭后恢复；沉浸模式隐藏小地图和画布工具栏。

## 自动验收

1. `node --test src/components/minimapGeometry.test.js`：缩放、负坐标、远坐标、SVG留白/尺寸取整、旋转边界。
2. `npm run dev -- --host 127.0.0.1 --port 5194 --strictPort`；设置 `PLAYWRIGHT_MODULE` 为本地 Playwright 的 `index.mjs` 路径，再运行 `node scripts/test-minimap.mjs <输出目录>`：真实浏览器交互、事件隔离、备注同步、内外开关记忆、主题及响应式布局。
3. `npm exec tauri build -- --debug --no-bundle`；运行 `node scripts/test-minimap-native.mjs <独立测试目录>`：真实Tauri/WebView及SQLite视口保存、文字同步、正常退出重启恢复。测试使用debug专属 `CREATIVE_CLOTH_TEST_DATA_DIR`，并验证数据库路径确实位于独立目录，调试端口9457。
4. `npm run build`、`npm run test:theme`，以及已有画布坐标、抽屉几何/拖动回归测试。

真实桌面验收结果和截图写入各自测试输出目录。源码和程序归档只追加；标准发布程序若仍被使用，先保留可用的独立版本，待用户正常退出后替换并核对哈希。
